# 给剪辑代理的本期输入

把以下内容填完，连同本地素材路径或已连接的 ChatCut 工程交给代理。不必提供密码、API key 或他人的账号。

```text
使用 $portrait-editorial-explainer 制作本期竖屏口播。

素材类型：真人原始口播 / 已粗剪真人口播 / 已定稿数字人 / 只有音频 / 只有文案
人物视频或 ChatCut 工程：填写实际可访问路径或工程标识
主声音：原视频人声 / 已定稿独立音轨
主题与受众：
必须保留的观点或段落：
希望删除的内容（没有可留空）：
目标时长：按完整语义决定 / 指定时长
真实证据、截图、产品素材：
参考风格：包内 V3 / 另给参考
输出目录：

真人原始素材先用 ChatCut 粗剪，数字人默认跳过。
以最终口播时间轴安排镜头、字幕和音乐，保持原人声与保留片段原速。
提供最终 MP4、可编辑工程、字幕、素材来源和实际验证结果。
```

路径是你自己的本地路径；代理无法访问时先解决素材访问，不用示例路径假装导入成功。只有文案时，先准备定稿声音，再校准字幕与镜头。
