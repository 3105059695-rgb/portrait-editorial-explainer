# 空间、数据、网页与真实素材：16 个可组合机制

这些机制来自完整参考中的不同段落，不要求一条视频使用全部效果。先看口播这一句在表达什么，再选择动作：对比就改变数值关系，复制就移动那一份内容，讲人物或案例就放真实影像。不要把每句话都变成一种卡片。

所有字段在 episode JSON 中配置，时钟为场景内秒数。`reveal` 是主体就位，`act` 是关键操作完成，`resolve` 是结果落定。它们应跟口播事件对应，按本期声音重新设置；默认示例时间不是通用剪辑节拍。

## 通用输入

- `content.items`：当期对象。每个对象有稳定 `id`、显示 `label`，可带 `image` 或 `video`（项目 `public` 下相对路径）。没有媒体时只显示可运行的原生示意图，正式视频应按内容配置素材。
- 视频可设置 `trimStart`（秒）、`playbackRate`、`fit: "cover" | "contain"`。嵌入的视频静音，口播使用顶层音轨；素材在本场景开始处起播。
- `title / content.kicker / content.body / content.result`：主标题、眉题、正文、结果句。保持屏幕文字短于口播原稿，长文本应拆成下一镜头。
- `content.selectedId`：必须是 `items` 中一个 ID。它是当前动作的主对象，具体含义见下表。
- `content.pack.showTitle: false`：由素材本身承担标题时关闭外部标题。
- `scene.camera`：独立镜头关键帧；可以改变焦点、缩放与旋转，无需更改物件代码。坐标以 544 宽的逻辑画布为准。
- 支持 3:4 与 9:16 按画布高度重新排布，物件本身不纵向拉伸。长列表应拆镜头，不能依靠缩小到不可读来容纳。

## 空间与数据

| mechanism | 发生的动作 | 本期输入和可调项 |
|---|---|---|
| `object-array-flip` | 物件沿不同路径落入斜向阵列，逐一翻面，再汇聚到主对象 | 每个 item 的 `image` 是正面，`replacementImage / replacementLabel` 是翻面后的内容；`selectedId` 是汇聚后保留的主对象；`pack.columns` 控制阵列列数。通常 4–12 件物件。 |
| `comparison-bars` | 条形从各自起点增长，数值同步变化，结果处圈出主项 | `item.value` 或对应 `content.values` 为非负值，最大值决定共用尺度；`selectedId` 指定圈选项；`metric.unit` 是单位。通常 2–4 项。 |
| `premium-coins` | 深色金边物件浮入，币粒在前后层下落，数值落定 | 第一个 item 的 `label` 是主体名称；`metric` 是主体数字；`emphasis` 可在无 metric 时提供中心短语；`pack.density` 调币粒数量。它适合等级、门槛、投入等语义，不应套在所有主题上。 |
| `cost-columns` | 柱体按真实数值比例向上增长，读数跟随，基准线贯穿 | `item.value` 或 `content.values`；第一项是基准线；`metric.unit`；各 item 的 `color` 可区分系列。通常 2–5 项。 |
| `quota-ring` | 环形配额从 100% 降到指定剩余值，结果章落下 | `metric.value` 为最终剩余百分比（0–100），`metric.label` 是环心小字，`result` 是最终印章短语。不是无条件清零。 |
| `gallery-camera` | 画廊由纵深透视展开为平面墙，再推进到选定作品 | `items` 提供实际图库；`selectedId` 指定终点；`pack.columns / speed` 控制列数和初段行进速度。少量输入会重复形成墙面，不会凭空生成新的素材。 |
| `curved-screen` | 整个网页世界在镜头中推进、倾斜并产生镜头畸变，纹理与暗角覆盖全屏 | `items` 组成页面图库；`url / kicker / title / body` 构成页面；`selectedId` 框选项目；`pack.angle / depth / focusX / focusY / columns` 调倾斜、畸变幅度、镜头焦点、列数。使用当前输入重建的网页示意，而非自动复原任意网站。 |

## 网页动作与真实影像

| mechanism | 发生的动作 | 本期输入和可调项 |
|---|---|---|
| `window-detail` | 在图库中选择对象，原页面侧移，详情窗进入，再推进 | `selectedId` 是打开的对象；`body` 是详情；`pack.labels[0]` 是详情栏名，`labels[1]` 是按钮；`columns` 改图库列数。 |
| `unlock-reveal` | 点击动作触发开锁，遮盖层移除，项目列表展开 | `items` 是解锁后可见的项目；`pack.labels` 为 `[按钮文字, 处理中提示]`，`result` 是成功结果。解锁只是画面表达，不会调用真实业务 API。 |
| `repository-copy` | 对链接选中复制，同一链接条沿弧线进入目标输入区 | `content.url` 是要移动的文本；第一个 item 作为仓库标题，其余 items 作为文件条目；`result` 是落定文案。仓库名与路径均由本期提供。 |
| `prompt-send` | 按时间输入指令、点击发送、消息上移、生成结果在下方展开 | `content.prompt` 为指令；`selectedId` 对应结果媒体；`result` 是结果提示；`pack.labels` 可替换 `[工作区标题, 输入提示, 已发送提示]`。 |
| `result-compare` | 结果纸张由中心展开为上下对照，连接线与高亮建立对应关系 | 各 item 是对比画面（图片或视频）；至少提供两项。每项保留自己的 label 和媒体，通常只用 2–3 项；`result` 写比较结论。 |
| `phone-focus` | 素材围绕手机建立关系，主影像进入手机，随后镜头推入屏幕 | `selectedId` 是手机主画面，其他 items 是外围材料；`result` 是屏幕内短句。支持真实竖屏视频；不要把任意横向截图强行拉伸。 |
| `curation-stamp` | 网格被扫描，选定内容盖通过章，其他内容变灰并盖退回章 | 设置 `selectedId` 表达唯一保留对象；省略时默认全部通过。`pack.labels` 为 `[通过文案, 退回文案]`，`columns` 控制网格。通常 3–9 项。 |
| `reward-transfer` | 币粒从来源沿连接线飞向接收对象，实际抵达后计数 | `selectedId` 是来源，其余 items 是接收方；`metric.value` 是总奖励数，`unit` 是单位，`pack.density` 是表现粒子数（不改变总奖励）。通常 2–5 个接收方。 |
| `media-stage` | 真实影像全屏入场，第二份素材横向接棒，镜头继续推进，文字贴合影像 | `selectedId` 是第一段影像，其后一项是接棒影像；只有一项时保持该影像并推进。`pack.direction: "left" | "right"` 控制交接方向；图片可做空间运镜，视频保留自身动作。 |

## 组合原则

一条内容可从真人/数字人或真实素材开始，在需要解释关系时进入网页动作或数据空间，最后用原片的漫画物件段表现抽象结论。表现方式之间通过主对象、文本指令、镜头焦点或匹配的视觉形状连接，而不是随机切换特效。

不要把 `media-stage` 的人物、`object-array-flip` 的物件、`gallery-camera` 的图像都留成默认图形，再称作完成真实素材剪辑。占位资产只用于运行与机制演示。正式构图必须使用用户提供、允许使用或新制作的本期媒体。

## 实现边界

- 阵列翻面是带厚度与投影的 2.5D 原生矢量变换，不是反求原视频物件的真实三维模型、灯光与遮挡。
- 曲面屏采用作用于整个页面的位移畸变，加上镜头旋转、网纹与暗角；不同素材仍需合理设置畸变幅度和画面密度。
- 帧内真实影像可以替换；本 Skill 不包含参考作者原视频、人物切图或私人数字人素材，也不会自动创造输入视频本身没有的表演动作。
- 网页为可编辑的操作示意，非真实可交互产品，也不执行复制、付费、解锁或上传请求。
- 这些是可组合的动画机制；不意味着任意题材仅更换文案即可达到原片质量。素材选择、镜头关系和口播事件仍由输入方案决定。
