# 已确认的目标：数字人口播的整套剪辑语言

这是本 Skill 的默认方向。基准是委托者已经认可的竖屏数字人口播 V3：人物开场，物件特写与回拉，具体物体动作带出资料，整屏曲面资料，再由画面里的物件接入漫画场景。UI 是这套视频语言的一部分。版本号更新、组件变多或代码可运行，都不能自行替换这个基准。

## 保留什么，重新设计什么

**保留设计做法**：明显但有阅读停留的景别变化；有形状、描边、高光和接触影的主题物件；真实资料与解释画面的对比；物体行动造成结果；物体边缘/表面/关联位置接出下一场；人物、人声和字幕保持同一叙事主线。

**按本期内容重做**：具体物体、资料、台词、布局、动作组合、镜头顺序、时长和语义落点。不固定钱币、公司、公文包、访谈人物、10.74秒，也不要求每期按同一套白—黑—紫顺序走完。只选本句话意需要的做法。

用户给数字人和口播时，任务是剪辑这段讲述。不要先发明一个应用，再把每句话改写成搜索、点击和保存。讲软件操作时可以使用完整 UI 段，但素材、景别与场景接力仍应服务本期讲述。

## 正例的具体动作证据

| 获认可 V3 的局部 | 应学会迁移的关系 | 新题不应照搬的内容 |
|---|---|---|
| 约2.6秒钱币特写，约3.5秒公司特写，其间回拉 | 先让被讲到的物件占据视野，再恢复多个对象的关系 | 钱币、公司及这些固定秒数 |
| 公文包沿弧线离开起点、抵达终点 | 把动词变成真实可见的物体行为 | 所有新话题都变成“去上班” |
| 约6.2秒包面直接展开访谈 | 前景的具体表面成为下一场入口，窗内已经是后景 | 每次都用公文包、黑矩形或相同转场时长 |
| 访谈作为整屏深色曲面资料 | 资料、边框、工具栏共同形成有景深的证据场；字幕/人物独立 | 假造新的访谈证据，或把任何段落都塞入浏览器 |
| 约8.2秒便签位置接出漫画；红线穿过胶片 | 换到完整的解释场景，让关系线与道具把话意演出来 | 固定黄色问号、三格访谈和紫色背景 |

## 已明确跑偏的做法

RC2 的“资料工作台”和“行程安排”仅有应用窗口、控件状态和小幅缩放。用户已明确否定它们作为目标风格的代表。它们保留为辅助 UI 技术例子，不能再当作正向风格样板。

下面任何一项出现，都应在交给用户之前回到镜头设计处理：

- 本来讲人物、概念或关系，整段却困在一个矩形应用里。
- 只有标题、列表、按钮改字，缺少主题物件或资料参与叙事。
- 用统一圆角、浅色和投影代替材质、景别与场景变化。
- 只把数字人贴成小窗，就称已经迁移了完整视频风格。
- 只通过 JSON/类型检查或静帧好看，就宣布和参考接近。

这是具体失败案例的纠偏，不是禁止所有软件教程、静镜或界面操作。看本期内容是否需要它们；不得为了满足清单乱加运动和漫画。

## 日常直接剪辑，必要时再对照

制作前，用四列写本期开头：**原话 → 主题物件/真实资料 → 发生的动作 → 景别与下一场如何连接**。优先用已有成熟做法，表达不了再扩展。不要先决定一套固定场景再把文案塞进去。

生成后对本期开头做必要成片检查：声音、字幕、人物、素材与转场能正常呈现，然后直接给用户看视频。已掌握的风格不需要每期重新拆参考或制作对照图、对比片、评分表。首次学习新参考、用户明确说不像或要求比较时，才针对该问题检查特写力度、物件材质或衔接方式。不能仅凭动画数量打分，更不能替用户认可。

## 工程能力边界

公开的 `assets/presenter-v3-template` 保留获认可案例的镜头实现，人物和访谈采用占位素材。这是视觉校准和源码参照，不是新一期的固定模板。通过显式 `new_project.py --case presenter-v3` 查看；不可只换媒体路径就宣称适配了新口播。

新分镜使用 `assets/adaptive-template` 的 `scene.editorial`，详见 [可复用动效契约](editorial-motion-contract.md)。此前缺口已经实现：`transitionAnchor` 精确跟随物体表面（含旋转、缩放和相机）；窗口内的下一世界沿实际时钟播放，支持负局部时间预演；`filmstrip` 支持可变素材数量、胶片惯性入场和逐格红线；`presenterStyle` 支持竖向倾斜人物窗或圆窗。自定义共享相机、物件关键帧和 `titleKeys` 让本期变化跟随口播。

这些能力通过新增可复用代码提供，不再要求每个调用者从旧片迁移它们。物件的造型来自本期SVG/PNG/JPEG/WebP素材，材质与构图仍需要按新内容制作。没有实现的其他效果须单独开发与验证；技术测试不能替用户认可新样段。

日常制作优先改分镜数据；当前实现位于 `assets/adaptive-template/src/EditorialScene.tsx`、`editorialMotion.ts` 和 `Film.tsx`。旧视觉校准代码位于 `assets/presenter-v3-template/src/`：`FilmV3.tsx`、`CareerActionV3.tsx`、`ComicThreadV3.tsx`、`PropsV2.tsx`。只在扩展确实缺少的做法时再参照旧源码，不保留旧台词和绝对时间。

低能力模型应复用这些成熟实现及有边界的动作模块，减少重新设计动画代码；不能靠把成片简化成普通 UI 来降低任务难度。尚未通过新题实际样段验证的模块、模型和组合，明确标记为未验证。

## 固定的制作流程

已有真人原始口播先经 ChatCut 粗剪；数字人默认跳过粗剪；已有粗剪和最终配音直接进入实测时间轴。先做本期真实开头10–15秒，用户认可后继续全片。没有本期素材时说明缺口，不拿无声无人的机制演示替代它。公开包不依赖作者私人路径、账号、人声或参考原片。
