# 原片后段：11 个可换内容的漫画空间效果

本组重建原参考片约 115–140.5 秒出现的表现方式。它们只是完整剪辑语汇中的一个段落。整条视频不要全部使用本组，也不要把纸张排版、真实界面、素材拼贴、物件翻转等前段语言改成漫画。

这些组件没有原视频、私人数字人或裁下来的原片图片。默认物件由代码绘制；提供 `image` / `video` 后，组件使用用户素材。默认色彩、粗细有变化的描边、厚度、遮挡、玻璃、人物、动态字形都保留在代码中。

## 所有效果共用的输入

- 场景使用相对时间：`start` / `end` 是整片秒数，`marks.reveal` / `marks.act` / `marks.resolve` 是**本场景内部**秒数。例如一个 4 秒场景可用 `0.7 / 1.8 / 3.6`。按配音语义安排，不必套固定时长。
- `title` 是本场景标题；`content.result` 是后段揭示的结论；`content.body` 是可选补充，具体可见位置见下表。标题过长会缩小，应主动写短。
- `content.items` 是本场景的真实主角，每项有 `id` / `label`，可加 `color`、`image`、`video`、`value`。`image` / `video` 是工程 `public/` 下的相对路径；视频支持 `trimStart`（秒）、`playbackRate`、`fit`。仅使用有权使用的素材。
- `scene.camera` 控制整体世界的焦点、缩放、旋转，时间为场景内秒数。坐标基于 544 宽；逻辑高为 `544 × 视频高 / 视频宽`。对象比例保持不变，竖屏通过锚点重新排布。
- `background` 优先于组件的默认底色。不要给整套示例统一设置白色背景，否则会覆盖原本不同的视觉世界。
- `content.pack.showTitle: false` 隐藏普通顶部标题；其他语义内容保留。`celebration-type` 的主文字就是动画主体，使用 `content.emphasis` 覆盖它，而不是隐藏普通标题。

| `upload-beam` | 浅蓝云端接收下方沿曲线飞入的内容；每一张素材到达后进度才增加。适合上传、汇聚、入库、交付。 | 所有项循环成为上传素材，`result` 或 `title` 标记云端目的地；`body` 为底部一句话。 | `metric.events` 控制到达次数，取项目数与设定值的较大值，设定值最多 30。进度是实际到达数百分比。 |

## 换主题时先换角色关系，再填素材

例如讲“团队素材怎样进入公共资料库”，可以使用“各成员制作的文件 → 上传汇聚 → 中央资源共享”的关系。不要因为原片用了机器人，就给所有主题也画机器人。

下面是一段可放入 v3 `scenes` 的场景。它表达共享关系，人数、头像、标签、数值和时机均来自输入：

```json
{
  "id": "team-shares-library",
  "start": 9,
  "end": 13,
  "mechanism": "sharing-network",
  "intent": "说明四个岗位在使用同一份资料，强调共享带来的协作",
  "title": "大家共用一份资料",
  "presenter": "pip",
  "marks": {"reveal": 0.65, "act": 1.75, "resolve": 3.55},
  "content": {
    "items": [
      {"id": "research", "label": "研究", "image": "assets/researcher.png", "color": "#69cef0"},
      {"id": "design", "label": "设计", "image": "assets/designer.png", "color": "#f391be"},
      {"id": "writing", "label": "文案", "image": "assets/writer.png", "color": "#ffda48"},
      {"id": "editing", "label": "剪辑", "image": "assets/editor.png", "color": "#78da8c"}
    ],
    "emphasis": "共用",
    "result": "各自制作，一起使用",
    "pack": {"speed": 0.8}
  },
  "enter": {"type": "circle", "duration": 0.3, "x": 50, "y": 48}
}
```

将这些文件加入工程后即可用真实头像。没有头像时删去各项 `image`，代码会绘制原生人物，仍可运行。涉及真实数字或价格时，传入自己的已核实数据；示例数据只是演示。

展示后反驳昂贵门槛，可以把一个场景写为：

```json
{
  "id": "expensive-access",
  "start": 13,
  "end": 16.5,
  "mechanism": "luxury-dome",
  "intent": "先呈现资源被当作奢侈品展示，再否定这种门槛",
  "title": "一定得这么贵吗？",
  "presenter": "hidden",
  "marks": {"reveal": 0.5, "act": 1.6, "resolve": 3.0},
  "content": {
    "items": [{"id": "resource", "label": "资源"}],
    "emphasis": "门槛",
    "result": "让更多人用得起",
    "pack": {"labels": ["ban"]}
  },
  "enter": {"type": "window", "duration": 0.25}
}
```

标题、价签、界面或字幕需要跟配音保持一致。`marks` 控制结果发生的时间，不是音频识别器；它们应由调用者根据已有配音填写。

## 已知边界

- 这是代码重建的可编辑视觉语汇，没有恢复原作者的 AE 源工程、原字体或内部素材。默认人物、星星、芯片等为独立的原生绘图。
- `remix-cube` 使用真实 CSS 3D 面；其他世界以 SVG 分层、厚度面和遮挡产生空间感，并不提供通用 3D 灯光/物理仿真。
- 不会把任意静态图片自动分割成关节或可动部件。替换媒体保留该组件的整体运动；需要媒体内部运动时，应提供视频或编写新的原生物件。
- 本组不负责生成配音或修改口型。数字人/口播视频由总时间轴接入，用户原始口播是否先粗剪由主 Skill 的输入流程决定。
