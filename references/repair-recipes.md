# 分镜与画面的修复配方

先修输入和结构，再修视觉；不要用新增滤镜掩盖错误。校验器错误以实际输出的字段路径为准。

| 问题 | 修改什么 | 怎样确认 |
| --- | --- | --- |
| 引用了不存在的对象或cue | 修正对应id，不靠复制字幕凑引用；同一对象保持唯一id | 重新validate，无未知引用 |
| 镜头留缝、重叠或超过片尾 | 根据最终口播校正start/end与duration，连带检查beats | 时间覆盖完整，无黑帧或多余静帧 |
| 动作落在字幕外 | 回听关键词，改beats.at或正确cueId，不能统一平移整片 | 抽看关键词前、中、后并听声音 |
| 原始真人还未粗剪 | 先完成ChatCut粗剪并建立映射；不是把pending改成done | 有实际剪后工程/文件和对应声音 |
| 估算时间被当作正式生产 | 完成声音与转写后重对齐；草案保留draft标识 | production校验及音画检查通过 |
| 缺音轨或素材路径越界 | 提供本期真实文件，使用素材根目录内相对路径 | 编译复制成功，不依赖作者电脑路径 |
| 所有镜头都同一机制 | 回到各句动词与关系，重选真正适用的动作 | 镜头变化来自内容，而非随机换预设 |
| 只有文本页在切换 | 将对象赋予前后状态，使用transfer/group/connect等实际动作 | 同一物体真的移动、进入容器或建立联系 |
| 字很长/太小 | 缩短标题与对象标签；信息留在资料或字幕，不删改事实 | 在竖屏实际大小查看最长文字 |
| 推近裁掉重点 | 修正focus对象、减少不必要对象，或修改本期组件构图 | 检查最大推近帧和回拉帧 |
| 人物遮住资料/动作 | 将本镜presenter设为hidden或调整专用布局；保留口播声音 | 人脸、关键证据、字幕不重叠 |
| 动作很忙没有读数停留 | 提前准备、延长同关系镜头、减少次要beats | 结果落位后能读完关键内容 |
| 曲屏字难读 | 使用清晰真实素材，缩短界面文字，必要时修改滤镜幅度 | 重点文本在编码视频中可辨认 |
| 圆窗像突然换页 | 检查渲染器显示的是新镜内容且旧镜在外侧保留 | 查看转场中间帧；不能只检查终态 |
| 真实图形基础组件表达不清 | 使用图片/SVG资产或实现新的机制组件 | 画面与本期专业含义一致，不能用任意图标代替 |

不要在没有运行工具、听看媒体时把以上条目全部勾为通过。验收记录分别写结构、实际渲染、视觉抽查、完整音画复核、用户认可。
