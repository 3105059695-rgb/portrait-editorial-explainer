# 可选的完整场景例子

新任务先读 [UI设计系统](ui-style-system.md)，用 [ui-stage自由编排](ui-composition-contract.md) 构建本期界面。下列六组是已有完整动作链，只有结构契合本句话意时才使用；它们不定义这类风格的边界。

当前六组组件取自同一条 140.5 秒、544×720 参考视频的具体动作研究。这里的“源时段”说明来源，不代表组件使用了原片画面，也不代表通过了用户审美验收。公开模板使用独立绘制的中性素材。

| 本句真正发生的事 | mechanism / 原片大约时段 | 必须保留的连续关系 | 适合变化的内容 |
|---|---|---|---|
| 多份输入汇成一个产物 | poster-route / 2–7 秒 | 海报先建立位置，线连接实际对象，再汇向产物 | 缩略图、海报标题、数量、产物名 |
| 从文稿找参考，选中并生成，再修改 | selection-build / 23–31 秒 | 文稿→候选网格→放大镜选中→同一对象升起→代码生成→输入→逐项翻面 | 正文、候选图、选中ID、显示代码、指令、前后图 |
| 网页上找到内容并带到另一个界面 | ui-handoff / 75–95 秒 | 列表→点击→详情→复制→同一URL移动→输入/发送→结果 | 页面项目、目标ID、链接、指令、结果 |
| 输入逐个进入处理，统计随之累积 | token-intake / 45.8–50 秒 | 票据弧线进入箱口并被遮挡，实际到达驱动累计 | 票据标签、最终值、单位、处理标签 |
| 身份与作品集关联 | creator-strip / 114.3–118 秒 | 徽章/皇冠/绶带依次建立，作品胶片持续横移 | 头像、身份标签、作品图、胶片项目 |
| 多项内容上传到同一处 | upload-progress / 118–120 秒 | 卡片依次离队→飞入云→进度同源增加→完成 | 文件/图片、目标名、各项配色 |

先写语义，再选组件。例如“对比两款净水器”不能被强塞成“生成代码”。现有六组不直接表达两物参数对照，可用ui-stage重新设计双物对照、字段和选择状态，也可用真实对比素材；确实缺控件时再扩展。选择组件是对动作关系的复用，不是主题分类。

详细参数见 [白底效果](source-style-white-effects.md)、[漫画和计数效果](source-style-comic-effects.md)。字段和时间约定见 [契约](source-style-contract.md)。

## 现有专用场景的边界（不要求逐个照搬）

目前没有把原片全部 140.5 秒封装进来。未实现的专用模块包括：低机位透视图库穿行、完整三维块旋转、手机从灰度到彩色并增添附件、赞踩淘汰与金币奖励、机器人状态/额度仪表、芯片入垃圾桶与玻璃罩的容器对照、逐字母聚合等。不能改一个参数就宣称这些都已复刻。

六个组件也有边界：网页默认是标记“示意”的原生界面；传入图片可换图库和素材，但不会自动逆向任意网站的所有交互。需要真实产品教程时应提供实录/真实截图并核对UI状态。替换人像和作品图会明显改变观感，应在本期开头再校准。

所有新模块当前状态：**原生实现；技术验证见交付记录；用户风格认可待定**。旧案例文件名里的 approved 不构成本次参考的认可。
