# 从参考提取的视觉与运动规则

优先依据参考的动作前、中、后三帧与连续播放。画面纹理只能辅助，身份连续、动作逻辑和节奏结构才使这组镜头有辨识度。

## 三种舞台

1. 编辑式白底：近白偏暖舞台，深色粗标题配少量锈橙关键词。纸张有轻薄边缘、柔和接触阴影、细框与微小倾角。主要物体足够大；小字不是背景装饰而是能读的操作依据。
2. 白底真实界面：保留页面的导航、列表、选中态、弹窗、输入框、发送和结果层级。镜头贴近当前操作，回拉时恢复上下文。别默认加CRT、扫描纹、暗角。
3. 漫画解释：浅紫、青、黄、粉、薄荷等舞台随语义切换；深色轮廓约3–4逻辑像素，硬投影、局部亮边、错位标牌、点阵/放射线。徽章、胶片、上传卡都具有自身形状和状态。

## 运动语法

- 先建立物体，再关注它，动作后让结果读得清。逻辑画布宽544，物体保持比例；竖屏增加可用高度后重排，不能纵向拉长。
- 相机围绕说到的对象行动。当前选中的同一对象进入下一工序；不要在每个镜头中心重新淡入一个相似图标。
- 细连线必须连接实物端点；放大镜围绕候选扫过后锁定；光标应先到点击位置再出现反馈；复制出的链接必须沿连续轨迹进入下一输入框。
- 数值由可见事件计算：物体到达→计数变化，不能一套粒子独立跑、一条进度条自己从0到100。
- 慢读数与快动作交错。转场通常0.2–0.4秒，在对象或窗口的位置接管；停留长度服从口播，不能所有场景统一3秒。
- 遮罩的两边都在运动。新镜头从真实的本地0秒开始播，并在展开后接着走，不能展开阶段冻结后跳回0。
- 只有徽章等适合有弹性的道具使用短回弹；纸面和网页更多平稳加减速。字幕不要每个字持续乱跳。

## 对照时记具体差异

分别看构图占比、焦点对象、动作路径、停留时长、遮挡关系、材质与文字层级。写“原片选择后同一个卡片上移，我这里新卡跳入，应保留一个实例的轨迹”，比写“再高级一点”更能指导修复。

技术检查不能给出“像不像”的百分比分数。实际看过哪些时段、抽查哪些帧、是否有用户明确认可，分别记录。不同主题对相同语法的适配不等于完全复制原片每个画面。
