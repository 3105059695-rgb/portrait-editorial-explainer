# 参考类型的视觉与运动语法

先用 [UI 设计系统](ui-style-system.md) 设计本期信息结构，再用这里的规则编排运动。要保留的是界面与物体讲解的气质，原片的选题、镜头顺序、转场次数不构成每期模板。

## 三种可选表达层

| 表达层 | 画面特征 | 适用时机 |
|---|---|---|
| 编辑式白底 | 近白舞台、明确标题、少量暖色关键词；纸面、图像和窗口有细边与柔和接触阴影 | 提出问题、整理证据、对照关系 |
| 有内容的界面 | 导航、列表或网格、详情、输入和结果各有层级；真实图像、短文本或数据支撑操作 | 解释产品、查找、筛选、比较、修改和结果反馈 |
| 漫画解释 | 浅紫、青、黄、粉等背景；深色轮廓、硬投影、局部高光与标牌，道具有可见状态 | 暂时离开具体应用，强调概念或因果 |

这三层可单独使用，也可按内容连接；没有必须轮流出现的顺序。参考中的网页并不是几张空白卡片：保留足够上下文与具体材料，再通过镜头控制阅读重点。真实 UI 保留原有结构，示意 UI 清楚标注。

## 运动的因果关系

- 建立物体 → 关注操作 → 发生状态变化 → 给结果阅读时间。可以在一个界面完成多句话，不必逐句换场。
- 当前对象保留 ID。选中、展开、移动或进入下一区域时，让观众仍能认出它；换个位置重新淡入相似图标不能替代对象接力。
- 光标先抵达，再点击，随后界面响应。光标只用于确实需要说明人机操作的场景；自动处理可直接用工作状态表达。
- 连线连接明确对象；替换前后保留对应位置；进度、数量或曲线有数据含义。避免图标乱飞与数字独立增长。
- 相机跟随当前阅读任务。先让人理解位置，再贴近关键字段，必要时回拉看结果与上下文；不是持续缩放整个界面。
- 纸面和网页多用平稳加减速；徽章、贴纸可短促回弹。字幕本身保持可读，强弱来自语义与落点。
- 快动作与阅读停顿交错。转场约 0.2–0.4 秒可作起点，最终随口播和动作复杂度调整，不把每场写成等长节拍。
- 遮罩两侧都继续运动。新场景从真实本地 0 秒开始走；展开结束后继续同一时间，不冻结再重启。

## 9:16 适配

参考为 544×720，竖屏在宽 544 的设计坐标下约高 967.111。新增高度用来重排操作区、解释、人物与字幕；不把旧画面纵向拉长。截图、人物和图像保持比例。上下文区允许暂时出镜，但相机靠近时应能看清当前操作。

## 对照记录

比较信息层级、内容丰富度、界面占比、焦点、对象连续性、运动速度及阅读停顿。记录可以是“我的详情区只有标题，参考还保留缩略图、状态和主操作；应补齐这些有效信息”，也可以是“展开后没停留，结果看不清”。

不是每个新镜头都需要匹配原片某个镜头。只在修复风格差异时查看相关证据；“同类 UI 的感觉”由整段观看判断，不能用技术通过率或像素分数代替用户审美结论。
