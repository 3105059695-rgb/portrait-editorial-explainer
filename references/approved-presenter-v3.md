# 默认视觉基准：已认可的竖屏口播 V3

本页是默认视觉校准依据，配合 [已确认剪辑方向](approved-editing-direction.md) 使用。代码案例本身不是新一期的固定模板。新一期先按口播设计物件、动作、景别和跨场衔接，再用本期分镜建立工程；通用底座缺少的成熟做法需要迁移，不能静默降级为应用界面演示。

## 认可范围

本技能从2026-10-10完成并获原委托者认可的竖屏口播 V3 中提取镜头与物体机制。公开分发版本将人物和访谈照片替换为明确的占位素材，移除原声音及私人认可记录。风格机制得以保留，公开占位样例并不冒充原成片。

案例：1080×1920、50 fps、537 帧、10.74 秒；人物来自用户已经提供的视频，原音频保持原速。风格认可不等于同一主题、人物、10 秒时长、公文包或每个固定坐标必须复用；下一期仍需独立交付和检查。

## 原片对照带来的修正

| 观察到的问题 | V3 中实际奏效的修正 | 新题的迁移方式 |
| --- | --- | --- |
| V2 常在同一纸卡尺度上翻面和淡入 | 近景约2.55倍的钱币→回拉→约2.40倍的公司→回拉 | 选择本期真正被讲到的对象做特写；保留共同空间和前一个对象，镜头随词义换焦点 |
| 仿旧米纸、暗绿覆盖太多场景 | 中性近白编辑舞台→深色证据屏→浅紫漫画场 | 根据解释/证据/比喻的语义选择视觉语言，颜色服务段落；不强迫每期出现全部三种 |
| “身份变化”停在卡片替换 | 公文包实际离开自己的公司，沿弧线到 OpenAI 意向端 | 将口播动词转成可见动作，例如送入、提取、检查、删除、合并、返回，而非只显示动词标题 |
| 访谈图只是居中的小照片 | 整个界面与照片一起曲面化和推近，占据主要视野 | 真网页、资料、产品UI或视频均可；模拟界面写“示意/编辑呈现”，保持证据和文字可读 |
| 黑色包面先遮满，再出现内容 | 扩展中的包面窗口已显示下一场访谈 | 旧景继续存在，窗口内播放新景，两者有可见的接力位置 |
| 漫画段仍沿用纸卡布局 | 从时长贴纸附近的黑边圆窗展开真实下一世界；立体问号→红线→访谈→胶片 | 圆心来自上个物件，线和道具表现关系；不能只用纯色圆罩后硬切 |
| 转场中字幕变成白字浅底 | 字幕独立于画面变形，漫画段加薄奶白底 | 检查转场中间态的对比度，不只看各场落稳后的截图 |

## 关键镜头参数：校准起点

均为逻辑 540×960，不是新片硬性常数。

- 人物开场满画面；约2秒进入解释后，半身框 x24/y678/w126/h165，字幕 y867。新人物的头部、手势和背景不同，重新裁切和避让。
- 钱币焦点 `(157,437)`、公司焦点 `(389,397)`，画布统一相机变换；不是每个元素各自乱飞。读数阶段保持可读，推近之后回拉。
- 近白底、铁锈橙 `#b65c3e`、黑描边；黑屏只承接证据；浅紫放射线只用于漫画段。纸纹很轻。
- 人物视频与字幕位于曲屏滤镜外。曲屏作用到照片、工具栏、边框整体；不能只把文字排成弧线。
- 音乐为轻量自制112 BPM底，13次动作音；这只是本期声音处理。长口播不持续每半秒加音效，音乐节拍不能反向迫使口播变速。

## 可编辑代码

只有显式 `new_project.py --case presenter-v3 --out <新目录>` 才创建该历史样例，其 Composition 为 `PresenterEditorialV3`。省略 `--case` 时必须提供本期 `--input` 分镜，编译到 `AdaptivePortrait`；不再自动复制任何示例。不要将两套工程的配置文件和渲染命令混用。两套工程均附有依赖声明、锁文件与代码，运行时不依赖作者的本地目录。

| 文件 | 可复用机制 |
| --- | --- |
| `src/FilmV3.tsx` | 连续人物主线、世界坐标相机、曲屏证据、包面开窗和黑边圆窗、独立字幕 |
| `src/CareerActionV3.tsx` | 同一公文包沿弧线移动，抵达后状态反馈，再由物体展开下一场 |
| `src/ComicThreadV3.tsx` | 问号、访谈圆框、完整胶片带、红线逐格连通 |
| `src/PropsV2.tsx` | 代码原生钱币、纸层、办公楼、轮廓、高光与接触影；V2命名只代表组件来源 |
| `src/mediaConfig.ts` | `presenterVideo`、`voiceTrack` 可为null；`referenceImage` 为占位SVG。配置路径相对于 `public/` |

这个历史样例保留原来的示例字幕、固定10.74秒与绝对时点，便于研究当时的相机和转场。它不承担自动适配新主题的职责；新的制作入口是 `本期 episode.json → new_project.py --input → AdaptivePortrait`；生成工程附带 STYLE_TARGET.md。需要从旧案例借用特殊机制时，只迁移合适的构图／动画实现，不沿用旧台词、物体或时长。仅替换历史媒体路径或台词不是完成剪辑。

## 验证与可移植性

历史占位提取的验证见 [V3 验证说明](validation-presenter-v3.md)，V1 公开发布记录见 [历史发布验证](../docs/VALIDATION.md)，v2 通用引擎的实际结果见 [当前验证](../docs/VALIDATION-V2.md)。历史风格认可与技术检查都不能代替新主题的视觉与声音验收。

官方 OpenAI 字标和位移图是历史示例资产；新题按实际品牌替换。占位图不可当真实访谈证据。公开包的预览全部来自占位工程，不含原用户或原风格参考视频。
