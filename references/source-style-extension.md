# 复用不足时如何新增镜头

新增机制的原因必须是现有动作无法表达本句，而不是为了每次重写动画。新主题通常先改JSON和用户素材；组件库不是封闭题材目录。

## 最小扩展交付

1. 写一句动作关系、要沿用的reference风格证据、与现有组件的差别。例如“同一芯片分别放进两种容器，对照其定位”；仅换名字不能实现遮挡关系。
2. 在新工程 `src/effects/` 新增组件，接收 `EffectProps`。输出SVG组，由父级提供544逻辑宽、随比例改变的height。继承 `motion.ts` 确定性函数，不用Math.random、Date.now或CSS时间动画。
3. 明确物体id、局部marks、素材槽、状态与遮挡。移动物体不要先销毁再在另一端重建；如果确需跨镜，给出连续的落点与接收轨迹。
4. 在types的Mechanism、Film的registry、校验器EFFECTS中注册名称与marks，同时给出1个最小JSON。需要新的content字段时同步types、validator与文档，别让轻量模型猜隐含字段。
5. 制作源比例与9:16局部预览。看前、中、后和连续播放，检查同一个对象的身份、景深、动作节奏、层次、文字大小、字幕空间。
6. 参数换成另一主题，确认图片/数量/标题/时间变化仍可用。技术通过只能标implemented；用户认可后才将对应样段标style-approved，注明是哪段而非全库获批。

所有资产从相对public路径读取；需要浏览器/模型/账号时运行时检测，不能写进作者路径。没有图片时用可辨识的中性示意并标示意，不能塞无关emoji代替主体。透视/3D效果必须实际处理景深与前后遮挡，不把2D缩放命名为3D。

开发者可以把已经验收的新增机制回收到Skill公共模板；本期私有配音、账号截图和版权参考保持在本期工程。无需让每一位使用者重新编写已验收效果。
