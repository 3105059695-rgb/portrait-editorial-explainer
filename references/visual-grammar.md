# 画面、材质、镜头与节奏

## 当前竖屏口播校准

2026-10-10的 [人物V3](approved-presenter-v3.md) 是口播任务的首选。先看 [公开样例画面](../docs/preview.jpg) 与 [静音机制预览](../docs/public-preview.mp4)；下方旧数学案例参数仅作为组件机制参考。

- 主舞台采用近白/中性暖灰，黑轮廓与铁锈橙突出焦点。纸张是物体材质，不把全片染成仿旧米色与墨绿。
- 景别敢于从全景推到局部：V3钱币约2.55倍、公司约2.40倍，随后回拉恢复双方关系；倍率随新对象调整。
- 深色证据屏可占据整个主要视野，工具栏、正文、照片、边框一起弯曲；人物和字幕保持独立平面。
- 漫画段使用浅紫/粉/蓝等明亮底、黑描边、实体道具。下一世界从前一个物体的圆窗/窗口出现，扩展过程中已能看到内容。
- 长短镜头依据语义安排，不把4个场景、112 BPM或10.74秒固定为所有口播模板。

## 从已批准画面提取的规则

本节可配合运行 `assets/approved-remotion-case` 查看。数值来自逻辑 544×720 的历史数学作品，是校准起点，不是所有尺寸必须照抄的参数。

| 层面 | 实际奏效的做法 | 改题后如何保留 |
| --- | --- | --- |
| 暖灰舞台 | 轻微径向明暗，边缘约 RGB 192/190/188，纸张奶油白 | 用环境明暗托住物体，避免整块纯白背景失去体积 |
| 纸张 | 薄边、折角、接触阴影与离面阴影分层；略有倾斜但正文可读 | 阴影跟随离地高度，前后纸页关系清楚；不要统一大而软的投影 |
| 物件尺寸 | 三个约 126×224 的海报在逻辑画面 x=49/208/367、y=231/208/185 错位；局部放大接近 2.9 倍 | 保持大小对比和前后层次；新稿不必再做三张卡，聚焦时敢于让边缘出框 |
| 原生材质 | 黑色橡胶箭头、金属指针、卷纸用轮廓、高光、渐变和接触影构造 | 先画对形状和受光，再加细颗粒；“立体”不能只靠 CSS rotate |
| 中文排版 | Noto Serif SC 用于编辑式标题与纸面；Noto Sans SC 用于 UI、漫画；拉丁数学可用 Tinos | 控制字号层级、行宽和留白，标题不是每个镜头都居中 |
| UI 特写 | 曲屏整体映射、轻扫描纹和暗角，内容始终是可读的操作对象 | 根据真实 UI 决定范围；局部畸变服务贴近屏幕的镜头感，不铺满所有纸张和漫画 |
| 漫画材质 | 约 2–3 逻辑像素黑边、纸折角、浅色放射背景、地面虚影 | 主体线宽一致，深浅结构明确；装饰星点只承担少量节奏 |
| 字幕 | 544 宽时约 18–22 逻辑像素，通常底距 32；编辑器段抬到约 65 | 按最终显示大小检查可读性，避免关键对象与字幕争同一块区域 |

## 一镜内部必须有过程

例如“这份报告需要检查”：

- 报告沿上一镜的运动方向进入，停在可阅读的位置。
- 口播提到检查时，光标/手/放大镜从现有状态出发寻找具体段落。
- 相机随选中段落推近，其他内容作为背景关系保留。
- 检查产生真实可见的批注、标记或状态；保留短暂停顿读懂结果。
- 被批注的同一张纸转交到下个动作，或通过它的边缘遮罩转场。

这种链条可以换成搜索→筛选→打开证据，输入→执行→核对，问题→拆分→归组。不要只把“检查”两个字放大代替动作。界面中的装饰光标不能假装已经执行了没有结果的操作。

## 镜头与物体如何配合

- 先在世界坐标安排物体，再让相机追随关注点；避免每个对象独立乱飘，无法判断空间。
- 运用物体的边缘、选区、文件夹口、窗口遮挡做交接。移动方向、接触点和前后层级应连续。
- 预备动作通常短于读数停留；大位移可在起止处减速、中段加速。弹性仅用于有重量或漫画夸张的物体。
- 大幅推近后安排回拉或横移恢复关系；持续微缩放不能替代真正的镜头编排。
- 对比多个对象时保留共同参照。念到第三项时抬高第三项层级、调整相机，验证它没被中间项挡住。
- 数据动画先建立总体，再在说到子集时标记子集。比例/数字出现时必须与口播含义一致；动画不可凭空增加精度或结论。

## 字幕、音效和动作落点

一个关键事件有三个时间：准备、落位、读完。旁白关键词通常锚定落位；准备可以略提前，具体提前量由动作长度决定。BGM 的重拍可以对齐视觉落位，不能反过来把重要语义割碎。

短促新闻碎片或特写串可以在开头制造速度，随后给关键判断留可读的静止区。高密度剪辑与较长连续镜头交替，不设“每两秒一切”的硬规则。音效避免每字一响，选择/点击可以轻，碰撞/盖章可以重；同一次落地不要叠满多个重击。

## 9:16 重排

旧数学案例实际是 816×1080，约 3:4；当前人物V3已独立按1080×1920制作并获风格认可。新作需要1080×1920时：

1. 用新的逻辑画布如 540×960，按宽度保持纸、字、描边比例，再重设 y、路径和相机目标。禁止只改变导出尺寸或使用 scaleY。
2. 更多纵向空间用于运动路径和景深：如顶部来源、中央执行、下方结果；正文主体仍占足够面积，不把旧画面缩在中央。
3. 字幕安全区根据平台或用户要求设置。未指定时可从左右 8%、顶部 6%、底部 12% 开始；这些是检查起点，不是任何平台的保证值。重要字幕通常在底部安全线以上。
4. 三卡横排可能要改成错层的两前一后、纵向接力或单张特写。保留语义关系与动作，不必保留横向坐标。
5. 重新检查最宽标题、最长字幕、角落 UI、小号日期、物体进入与离开画框的路径；导出实际 9:16 样段确认。

## 用户说“还差质感”时的判断顺序

先找具体证据，而不是堆滤镜：

| 现象 | 优先修复 |
| --- | --- |
| 只有文字换页 | 把一句话画成对象与操作，保持同一对象跨步骤 |
| 像平面卡片 | 改主物体的体积、接触影、前后遮挡和尺度差 |
| 东西很多但不知道看哪 | 镜头跟随被讲到的对象，削弱次要层 |
| 动得快但没卡上话 | 检查关键词的实际发声时点，重排落位与停留 |
| 数字或段落看不清 | 延长读数，减少畸变/扫描纹，修改裁切与层级 |
| 同一套模板感强 | 改开场的语义事件、对象路线和解释道具；保留材质系统 |
