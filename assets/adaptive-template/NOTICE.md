# Adaptive portrait renderer

Original reusable mechanism implementation distributed with portrait-editorial-explainer under MIT (see LICENSE).

The local radial displacement image `public/media/lens-map-v3.png` and font import list are reused from the bundled `presenter-v3-template`. No user portrait, narration, interview, brand image, or licensed stock material is included. The default JSON is a silent, explicitly marked demonstration about sorting customer questions.

Fonts are installed from the pinned @fontsource packages. Noto Sans SC / Noto Serif SC use SIL Open Font License; Tinos uses Apache License 2.0. The packages contain their respective license files. Rendering needs no remote font or content service.
