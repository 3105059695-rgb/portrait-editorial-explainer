# 3.3：直接接入本期素材

沿用已确认的3.2完整效果实现。本轮没有修改Remotion组件与整体视觉定义，新增的是查找、填写、对齐字幕和生成独立工程的入口。

## 使用上改变了什么

- `effect_library.py find 关键词`：按用途和标签检索效果，不冒充模型语义搜索。
- `effect_library.py describe EFFECT --json`：覆盖46个入口，列最小shot、动作名、必填/建议/可选内容、实际绘制数量和生效参数。可只读取当前选中的效果。
- `start_episode.py`：已有SRT以原字幕序号引用镜头与动作，转换为镜头内时间并保留关联关系；直接生成可运行Remotion工程。
- 同一入口接入最终配音、数字人或实际完成粗剪的人物视频，素材保存为相对路径。默认正式校验；演示须显式draft，不自动降级。
- 保留输入brief、生成episode、原SRT与报告，方便换素材、改动作、追溯字幕。用户给文件和意图，Agent完成配置工作。
- 安装、直接调用、故障说明已指向新入口；完整v3/v2旧分镜仍兼容。

## 适用边界

字幕入口使用调用者提供的SRT，验证动作落在关联句子的区间；没有自动生成词级时间，也没有判断字幕是否真的对应声音内容。语义选择和重音落点由Agent依据本期素材完成。

没有做跨低模型盲测，也未在本轮重新生成数字人、调用ChatCut或声音克隆服务。通过固定的效果实现和时间换算减少模型工作量，不承诺所有模型产出相同审美。

这份文件记录包的开发验证，不是每期制作必须重复的审查流程。日常直接制作并检查本期开头。
