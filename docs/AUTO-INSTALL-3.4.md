# 3.4 自动安装验证记录

验证日期：2026-10-13。范围：Windows x64，一段安装说明交给可执行本机命令的 Agent；未测试 macOS、Linux、ARM64 或所有模型。

## 实际完成的检查

- 使用已有本机工具完成安装、依赖准备、浏览器下载、渲染与全帧解码。
- 使用独立 app-home / skills-dir，强制忽略系统工具，实际下载并校验 Python 3.13.16、Node.js 24.21.0、Remotion 4.0.534 媒体工具；使用该环境安装 359 个锁定的 npm 包并实际渲染。
- 修复后重复运行安装主流程，结果为 `ready`；已有工具与浏览器得到复用，升级备份被创建。
- 示例输出为 540×960、30fps、360帧、12.0秒；FFprobe检查及FFmpeg全帧解码通过。
- 原有与新增Python测试合计126项：121通过，5项因本机Windows符号链接权限跳过。测试包含更新备份、额外文件保留、失败状态、运行时环境、依赖锁变化与浏览器缓存边界。
- C#编译与自测通过。ZIP/tar.gz解压检查覆盖路径越界、绝对路径、数据流、软硬链接、设备条目等；不修改系统权限来运行测试。
- 实际CMD调用效果参数查询返回可解析JSON，错误输出和非零退出码可捕获。中文、空格、百分号、感叹号等路径参数做了实际调用验证。
- 自动安装脚本使用固定Release资产、SHA256SUMS、独立临时解压目录和headless入口；不采用远程脚本管道到`iex`。

示例渲染验证的是工具链可运行。它是公开静音草案，不是用户本期成片，不代表所有模型或所有素材会得到相同审美结果。原3.2完整效果库及3.3字幕入口的视觉实现未在此版本改动。

## 调用约定

安装与制作的本机路径写入使用者自己的配置文件，不进入发行包。Agent在安装后优先通过`Use-Skill.cmd`运行已安装脚本；新生成的项目可以使用预览、开头、全片三个启动器。浏览器缓存缺失时恢复正常下载。

首次安装需要联网。Python、Node与媒体工具按固定散列验证；npm使用锁文件；Remotion获取其渲染浏览器。网络或宿主权限阻止安装时必须报告具体失败，不将仅复制Skill文件视为成功。
