# v3候选版：实际实现与验证（2026-10-12）

当前状态：**可运行候选包，六组动作已实现；用户风格验收待定。** 本轮没有取得新的本期口播，因此成品是明确标记的无声机制样段，不能当作已完成本期口播。未进行本轮真实ChatCut导入/粗剪/导出或真人语音对齐验收。

## 已实现与技术验证

- 从参考的具体时段提取六组原生动作：海报汇聚、检索与替换、网页复制接力、票据计数、人物徽章胶片、上传进度。使用本项目独立绘制图形/旅行插画，不包含原片提取图、音频、作者头像或私人路径。
- 近源比例544×720和竖屏1080×1920均实渲；原生物体保持比例，竖屏调整间距。未声称原片全部140.5秒已经组件化。
- Node24.18.0、npm11.16.0、Python3.11.15、FFmpeg8.1.1；新工程实际 `npm ci` 安装359个包，依赖锁可用，TypeScript检查通过。npm提示锁定ESLint版本已不受支持；未在本次风格工作中升级整个工具链。
- 测试总计60项：56通过，4项因Windows不允许创建测试用符号链接而跳过；新v3的15项全部通过。覆盖时间/字幕/marks、转场重叠、缺失素材、路径越界、禁止覆盖旧工程、媒体哈希复制等。最后计数接口及示例变更后重跑v3相关15项通过。
- `doctor --profile production`通过；Skill结构校验通过。ChatCut连接不在doctor验证范围。
- 默认新建工程成功；没有approval文件时 `npm run render:full` 实际返回失败，未启动全片渲染。此为流程防误触，不是用户身份认证。

## 与原片对照

本地比较过四组对应阶段：选择对象上移、托盘逐个替换、徽章与胶片、上传云与进度；原片证据只保存在本地分析目录，未打进公开仓库。白底/漫画的构图与结构有具体参照。

差距仍包括：原片真实截图和内部动效更丰富；示例采用中性原创图；细部字体与路径尚未逐帧拟合；示例节奏适配演示时间，未进行原片音效/BGM的逐拍恢复。最终“人眼觉得差不多”须由用户看连续样段判断，不能用机器分数代替。

## 轻量模型实测

真实使用gpt-6-luna、low推理，在只读Skill与必要文档、只写新JSON的范围内编排“读书摘录”。初次契约校验通过；人工发现6条索引与84张比例票据不一致，组件增加events接口后，由该模型补上events=6再通过。其三镜头顺序、文字、时长、数量没有沿用旅行模板。后续集成用其最终JSON完成实际渲染。

这说明组件减轻了代码负担，同时也说明语义判断仍需纠正；只有一个主题试用，不能推广为所有轻量模型和所有题材都能自动达到同一水准。[原始过程](../examples/source-style/MODEL-TRIAL.md)
